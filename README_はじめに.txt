BIG ARCH 公式サイト（無料公開用）

1. index.html をダブルクリックすると、パソコン上でホームページを確認できます。
2. 写真は images フォルダにあります。index.html と style.css と images フォルダは一緒に保管してください。
3. 公開するには GitHub の無料アカウントを作成し、新規公開リポジトリ（例: big-arch-site）にこのフォルダの中身をアップロードします。
4. GitHub リポジトリの Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save を選択。公開URLは https://ユーザー名.github.io/big-arch-site/ になります。
5. GitHub Pages の公開リポジトリは誰でも閲覧できます。住所や個人情報、許可のない雑誌画像をアップロードしないでください。
6. 無料サービスは永久保証ではありません。元データを外付けSSDなどにも複数バックアップしてください。
