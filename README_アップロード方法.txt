1. ZIPを解凍します。
2. GitHubで bigarch3110-star / big-arch-website を開きます。
3. リポジトリの一番上（assetsフォルダの中ではない）で
   「ファイルを追加」→「ファイルをアップロード」を選びます。

   history.html は既存ファイルの更新となります。
   index.html / secret.html / riders.html / team.html は上書きしません。
